# 🔊 Text to Voice

A modern browser-based Text-to-Speech application built with JavaScript and Web Speech APIs that converts written text into natural voice output in real time. The application provides voice selection, adjustable speech controls, and a clean interactive user experience directly in the browser.

# 🔊 How It Works

The application uses the browser’s built-in Speech Synthesis engine through the Web Speech API to convert user-entered text into audible speech in real time.

Users can:

- Enter custom text
- Select different voices
- Control speech speed
- Adjust voice pitch
- Generate speech instantly
- Listen directly in the browser
